---
title: Objects off the map no longer reveal the shroud
category: fix
release: 0.2.0
targets:
- type: system
  id: map-visibility
  effect: changed
credit: [ZivDero, JoyfulShush]
---

An object that had left the map could still reveal the area around its last position when the game updated its sight. Only objects on the map reveal the shroud now.

JoyfulShush is credited for the Vinifera fix this follows.
