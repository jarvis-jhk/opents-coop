All players of a shared-house campaign now share its control groups. A group one player assigns shows its number on every player's screen, any player who controls those forces can select it, and a shared save keeps it. Each player used to keep separate control groups that a load cleared.

Assigning a control group also sets the object's recruitment group, as in a campaign played alone. Skirmishes and other networked games keep each player's control groups local.
