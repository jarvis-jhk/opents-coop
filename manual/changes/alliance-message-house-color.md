---
title: Alliance messages use the house's color
category: fix
release: 0.2.0
targets: []
credit: [ZivDero, Rampastring]
---

The message announcing that a player has allied with another used to appear in the color of the player's country, which can differ from the color the player chose for the match. It now appears in the player's own color.

Rampastring is credited for the Vinifera change this follows.
