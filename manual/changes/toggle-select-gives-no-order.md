---
title: Shift-clicking an object only changes the selection
category: fix
release: 0.2.0
targets: []
credit: [ZivDero, JoyfulShush]
---

Shift-clicking an object to add it to the selection or remove it also passed the click to the selected objects as an order, so a selected medic or other healer could switch to area guard. A Shift-click now changes only the selection.

JoyfulShush is credited for the Vinifera fix this follows.
