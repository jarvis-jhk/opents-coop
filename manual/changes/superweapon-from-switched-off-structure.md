---
title: Superweapons from switched-off structures arrive suspended
category: fix
release: 0.11.0
targets:
- type: system
  id: superweapons
  effect: changed
credit: [ZivDero, Rampastring]
---

A superweapon granted by a structure that was switched off, such as one a map places powered down, used to start charging anyway. It now arrives suspended unless another switched-on structure grants the same weapon, and it resumes when one is switched on.

Rampastring is credited for the Vinifera fix this follows.
