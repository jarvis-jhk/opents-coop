The campaign dialog has a **Mission** list. Choose any mission the campaign reaches to start there, for example to test an edited mission or variant without playing the earlier missions. Missions after the first start without the credits and global flags earlier missions carry over. See [Campaign mission variants](/formats/campaign-variants/#start-from-a-later-mission).
