---
title: Computer healers keep their allied targets
category: fix
release: 0.11.0
targets:
- type: system
  id: target-selection
  effect: changed
credit: [ZivDero, JoyfulShush]
---

A computer-owned medic, mechanic or other object whose weapons heal used to drop an allied target on its next update, so it could not heal allies. Such an object now keeps an allied target. Other computer-owned objects still drop allied targets, except aircraft and engineers.

JoyfulShush is credited for the Vinifera fix this follows.
