Shared-house campaigns now save on every machine at once from **Save Game** in the options menu and at the automatic-save interval. The host can load a save during play, or resume one later with the network lobby's **Load Game** button when the same players return. See [Resuming a saved game](/formats/spawn-ini/#resuming-a-saved-game).
