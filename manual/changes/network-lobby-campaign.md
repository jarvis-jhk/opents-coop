The network game setup has a **Campaign** button for the host. Choose a campaign, mission and difficulty, wait for every guest to accept, and press **Go!** to start a shared campaign on every machine without writing launch files by hand. See [A shared campaign from the network lobby](/formats/spawn-ini/#a-shared-campaign-from-the-network-lobby).
